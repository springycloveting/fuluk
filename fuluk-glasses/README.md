# Fuluk Glasses（Rokid AIUI 智能体）

手机 APP 的“助手”功能在 Rokid Glasses 上的移植版。

## 功能
- 唤醒：说“乐奇”或点击镜腿唤醒语音输入。
- 语音输入：系统 ASR 出原文（ASR 不加任何提示词），再交给系统 LanguageModel 勘错（重点纠正“绘画→会话”等术语），勘错完成后直接发送，无需确认。
- 指令通过 `/api/nl` 发往 fuluk-gateway，自动携带当前会话 ID，无需再说“查看 XX 会话”。
- 说“切换会话”进入会话选择：只显示非已关闭会话；可语音说名称定位，或滑动镜腿移动光标、点击镜腿确认。
- 说“切换模式”在助手与 TUI 之间切换。TUI 显示终端输出，内容先进“待输入”框：可说“把X改成Y”“把所有X改成Y”“删除X”“加上X”“清空”修改，说“发送”或点击镜腿提交。
- 说“透明模式”进入极简空屏页面，仅保留一个几乎不可见的状态点；页面在前台持续挂载，低频监听会话确认通知。唤醒后说“助手”/“切换模式”回助手页，说“终端”回 TUI。
- 助手回复自动 TTS 朗读。
- 会话需要确认时自动跳转确认页：点头/确认键同意，返回键拒绝。
- 会话列表页：上下键切换、确认键选择，待确认会话有 [待确认] 标记。

## 上传封装
1. 将本目录打包为 zip（见仓库根目录的打包命令）。
2. 在 Rokid 开发者平台 Web 端选择“导入智能体/从本地导入”，上传 zip。
3. 封装时网络白名单需加入网关地址（如 `192.168.0.55:8787`、`100.64.0.7:8787`），并允许 HTTP 明文局域网访问。
4. 首次打开进入“眼镜配对”：语音说出地址和端口。
5. 在电脑 Web 端点“配置 → AI眼镜认证”，批准该眼镜；批准后双方保存密钥，以后无需输入 token。
6. 如需取消授权，在同一页面“已授权眼镜”中撤销。
